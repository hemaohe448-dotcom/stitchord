# 05 生产质量与工业上机

> 本文定义“什么叫能上机”。所有阈值都是**默认基线**，必须由目标机型、面料、线径与打样结果校准；
> 未经试缝验证的数字不得对外宣称。

## 2. 工艺约束（默认基线）

| 约束 | 默认值 | 说明 |
| --- | --- | --- |
| 单针最大长度 | 12.1 mm（DST 单条记录上限 121 × 0.1 mm；物理机可能允许 12.7 mm，但导出须拆分） | 超过需拆分或改为跳针 + 分段 |
| 单针最小长度 | 0.5 mm | 低于易堆线；短于 0.2 mm 直接合并 |
| 填充行距 | 0.35–0.5 mm | 视线径/面料；默认 0.4 mm |
| 缎面密度 | 0.35–0.45 mm | 过密易断线/起皱 |
| 拉布补偿 | 0.2–0.4 mm | 按面料/线径标定；针织取大 |
| 打底 | 边缘走线 / 中心走线 / 锯齿 / 填充 | 大面必做；小字慎用 |
| 起收针 | 3–5 针锁针 | 或按机器命令 |
| 剪线阈值 | 跳针 > 6–8 mm | 低于阈值用跳针，不剪线 |
| 框边距 | ≥ 10 mm | 夹持与走针安全 |
| 换色顺序 | 由浅到深 / 由外到内 | 减少污染与重复换色 |

## 4. 试缝协议（生产级验收）

### 4.1 样本矩阵

- 面料：平纹棉、针织（T 恤）、帽料、毛巾/绒面；
- 线：40 wt 涤纶绣花线，同一品牌同一批；
- 针：75/11 圆头（针织用球头）；
- 稳定：水溶膜 / 背胶衬 / 撕边衬，按面料；
- 图案：细线、小字（≥ 4 mm 字高）、大面填充、渐变/多色、边界锐角。

### 4.2 流程

1. 导出 DST/PES，记录参数与 hash；
2. 按标准流程上机（同一机型、同一张力、同一速度档）；
3. 缝合后拍正视/侧视/微距照片（固定光源、色卡）；
4. 水洗/揉搓测试（按客户标准）；
5. 由制版师按 rubric 打分并记录缺陷。

### 4.3 评分 rubric（1–5）

| 维度 | 5 | 3 | 1 |
| --- | --- | --- | --- |
| 覆盖/露底 | 无露底 | 轻微 | 明显 |
| 套色/对位 | 完全对齐 | 轻微偏移 | 明显错位 |
| 起皱/拉伸 | 平整 | 轻微 | 严重 |
| 密度/手感 | 均匀 | 局部不匀 | 过硬/过软 |
| 线头/剪线 | 干净 | 少量 | 多 |
| 整体可用 | 可直接交付 | 小修 | 重做 |

**生产级门槛**：平均 ≥ 4，且任一维度不得 ≤ 2；返工率 < 20%。

## 6. 发布门槛

| 阶段 | 必须满足 |
| --- | --- |
| Alpha（内部） | P1 + P2 AC；无阻断缺陷；导出可复现 |
| Closed Beta | P4 + P5 AC；安全自查；备份恢复演练 |
| Public Beta | P6 试缝达标；许可证/隐私合规；支持流程 |
| Production | 30 天无 P0 事故；SLA 可兑现；回滚演练 |

## 7. 宣称规范

- **“可上机 / machine-ready”**：通过静态校验并成功导出目标格式；不代表已试缝。
- **“生产级 / production-certified”**：在指定机型 + 面料 + 线材上完成试缝并达到 rubric；必须注明范围与日期。
- 禁止使用“任意图片一键生成工业级绣花文件”这类无法举证的说法。
- 照片反推功能未过 P7 门槛前，只能标“实验性”，并明确失败边界。
