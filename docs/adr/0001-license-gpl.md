# ADR-0001：项目采用 GPL-3.0-or-later

- 状态：已提议（待人类确认商业边界）
- 日期：2026-10-30
- 决策者：产品负责人 + 架构

## 背景

- Ink/Stitch：GPL-3.0（`inkstitch/LICENSE`）；
- Embroiderly：GPL-3.0-or-later（`embroiderly/README.md:29`）；
- 我们计划直接调用 Ink/Stitch，并可能修改/新增其扩展；
- 商业模式可能是托管 SaaS，也可能发行桌面/私有化版本。

## 决策

项目整体采用 **GPL-3.0-or-later**。商业价值来自托管服务、支持、模板、算力与工作流，
而不是闭源许可证。

## 后果

正面：
- 可以合法复用/修改 GPL 生态，升级路径简单；
- 对开源社区友好，便于吸引制版师贡献预设与测试语料。

负面：
- 若发行桌面/私有化安装包，必须提供对应源码；
- 不能把 Ink/Stitch 静态链接进闭源产品；
- 若未来必须闭源，需要架构级 clean-room 重做（成本高）。

## 备选

1. **闭源 + 独立进程隔离**：SaaS 可行，但桌面发行仍有义务风险；需要律师逐案评估。
2. **MIT/Apache 自研内核**：法律最干净，但要重写绣法/格式，周期以人年计。
