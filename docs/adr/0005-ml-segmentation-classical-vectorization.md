# ADR-0005：ML 分割 + 经典矢量化，不用端到端生成 SVG

- 状态：接受
- 日期：2026-10-30

## 背景

“图片矢量化达到精美”是核心诉求。端到端 image→SVG 模型（含 SVG-LLM）看起来诱人，但：
- 几何/尺寸/文字不可控，容易产生“看起来像”的幻觉；
- 无法保证闭合、无自交、最小特征宽度等制版约束；
- 难以解释和局部修正。

## 决策

采用可分解流水线：

1. ML 负责**语义**：抠图、分割、区域合并；
2. 经典算法负责**几何**：vtracer/potrace、简化、曲线拟合、拓扑修复；
3. 规则/优化负责**工艺**：绣法分类、方向、密度、补偿；
4. 人在回路修正，所有中间结果可回溯。

端到端生成模型只用于灵感/风格建议，不进入生产几何链路。

## 后果

- 需要维护多阶段流水线与基准集；
- 质量可度量、可定位、可回退；
- 对复杂照片仍需人工，避免过度承诺。
