# 03 路线图与验收标准

> 时间是以“1 名人类负责人 + 2–3 个智能体并行”估算的**相对工期**，不是承诺。
> 每个阶段只有全部 AC（验收标准）有证据才算完成；没有证据 = 未完成。

## 0. 阶段总览

| 阶段 | 目标 | 估算 | 出口里程碑 |
| --- | --- | --- | --- |
| P0 | 工程地基 + 可运行骨架 | 已完成 | G0：仓库/契约/文档/测试可复现 |
| P1 | Ink/Stitch 无头编译打通 | 1–2 周 | G1：SVG → DST 与针迹计划可控 |
| P2 | 图层化针迹编辑器 | 3–4 周 | G2：可手工完成一张可导出作品 |
| P3 | 图片自动矢量化 + 自动绣法 | 3–5 周 | G3：基准图自动初稿达标 |
| P4 | SaaS 化与生产加固 | 3–4 周 | G4：多租户内测可用 |
| P5 | 机器格式与工艺覆盖 | 2–3 周 | G5：主流格式/幅面/分框 |
| P6 | 质量与“精美”提升 | 持续 | G6：试缝评分达标 |
| P7 | 实物照片反推针迹（R&D） | 8–12 周 | G7：go/no-go 报告 |
| P8 | Beta 运营 | 持续 | G8：公开 Beta |

关键路径：**P1 → P2 → P3 → P4/P5**。P6 是质量门禁（需要试缝条件），不阻塞内测；P7 不阻塞主线，独立立项。

## P0 工程地基（当前）

**交付物**

- monorepo（npm workspaces + Python service）、CI、契约、ADR；
- 可运行的针迹查看器：DST/PES 上传 → StitchPlan → 画布渲染 → 导出 DST；
- 文档：可行性、架构、路线图、智能体手册、生产质量、开发环境。

**验收标准**

- [ ] **P0-AC1** `cd apps/web && tsc --noEmit` 退出码 0；`vitest run` 全绿；`vite build` 成功。
- [ ] **P0-AC2** `pytest` 全绿；DST 写入→读回，针数/色块/换色一致，包围盒误差 ≤ 0.1 mm。
- [ ] **P0-AC3** 独立评审（Claude/人类）对 `docs/01`、`docs/02`、`docs/03` 无阻断性意见；意见逐条关闭。
- [ ] **P0-AC4** 许可证与整合方案已记录为 ADR，且用户确认商业边界。
- [ ] **P0-AC5** 新机器按 `docs/06-dev-setup.md` 从零跑通前端构建 + 后端测试。
- [ ] **P0-AC6** `.gitignore` 覆盖研究克隆、缓存、密钥；仓库无第三方源码副本。

**证据**：CI 运行链接 / 本地命令输出、测试报告、评审记录。

## P1 Ink/Stitch 无头编译（最高技术风险）

**目标**：证明“我们的 JSON → SVG → Ink/Stitch → DST + StitchPlan”在无 Inkscape GUI 的容器里稳定成立。

**进展（2026-10-30）**：库调用路径已跑通（无 Inkscape、需 wxPython、输出确定），
完成 CompileDocument(mm) → SVG(px) → plan/DST 端到端（2 色块/3490 针），
fill/running/satin + PES，面料预设（woven/knit 实测差异），
`/v1/digitize` 已接入 3.11 服务并在网页生成（73 tests），12 例自引用黄金语料。
详见 `docs/research/inkstitch-headless.md`、`docs/contracts/compile-document.md`、
`docs/reference/parameters.md`；剩余：Inkscape 参考对比、Linux 镜像、DST 边界针差异固定。

**交付物**

- `services/digitizer` 镜像：Python 3.11 + Ink/Stitch 固定 commit（`d225262…` 起）；
- `compile_svg`：至少覆盖 running / satin / tatami fill / underlay / 多色 / 跳针；
- `stitch_plan_json` 扩展（GPL 补丁，公开）；
- 参数映射表 `docs/contracts/inkstitch-params.md`（每个属性附源码行号）；
- 黄金语料与对比脚本。

**验收标准**

- [ ] **P1-AC1** 镜像可离线构建；`docker run` 无需 Inkscape GUI、无网络即可导出（允许镜像内安装 wxPython/GTK；不得依赖 X11/桌面）。
- [ ] **P1-AC2** 12 份黄金 JSON × {DST, PES} 全部成功；相对参考 DST：针数误差 ≤ 1%，色块数/换色数完全一致，包围盒误差 ≤ 0.1 mm（跨 writer 时仅比较这些）。
- [ ] **P1-AC3** 同一份 StitchPlan 经 Ink/Stitch 导出的 DST 读回后，与计划逐点对齐容差 ≤0.17 mm；
  针数差 ≤3（DST 在色块起始/换色处的边界针行为，已记录），差异不得扩大。
- [ ] **P1-AC4** 同一输入连续编译 3 次，输出字节级 SHA-256 一致；DST 头名称固定（不含时间戳/随机值）。
- [ ] **P1-AC5** 2 万针文档编译 P95 ≤ 10 s（4 vCPU / 8 GB 容器）。
- [ ] **P1-AC6** 参数映射覆盖 ≥ 15 个实际属性；每个属性有 `path:line` 或 `.inx` 证据；未确认项标 `TODO(verify)`。
- [ ] **P1-AC7** 失败输入（缺属性、非法单位、损坏 SVG）返回结构化错误，不崩溃、不产生半成品文件。
- [ ] **P1-AC8** 明确记录 wxPython/GTK 依赖与启动方式；若采用惰性 import 补丁，补丁与许可证声明一并提交。

**停止规则**：若 P1-AC2 在 2 周内无法达到，或 wx/GTK 依赖导致无头运行不可行，改为“Ink/Stitch 作为库调用”的 B 方案，并重新评估工期；不得带着不确定的编译契约进入 P2。

## P2 图层化针迹编辑器

**进展（2026-10-30）**：MVP 已可演示——图层/对象列表、画布拖拽、颜色/针法/行距/角度/坐标、
删除、图层排序、撤销重做、自动重编译、localStorage 持久化、工程 JSON 保存/打开、
复制对象与键盘快捷键、曲线/折线节点编辑、自由绘制走线、图层显隐/删除、
打底预览开关、多选与批量操作、SVG 导入、导出。
**未实现**：锁定/合并/布尔、起收针/锁针、密度、100 步上限、Playwright、局部重算。

**目标**：制版师能在浏览器里完成“建层 → 画/导入形状 → 设绣法 → 调针 → 导出”。

**交付物**

- 图层树（增删改、排序、显隐、锁定、改色、合并）；
- 对象编辑（节点、变换、布尔、复制）；
- 针迹参数面板（绣法、角度、行距、密度、打底、补偿、起收针、锁针）；
- 命令栈（100 步 undo/redo）、自动保存、冲突提示；
- 局部重算（只重算受影响对象）。

**验收标准**

- [ ] **P2-AC1** 新建 3 层 / 10 对象 / 每对象 ≥ 3 种绣法，保存刷新后完全恢复。
- [ ] **P2-AC2** 100 步 undo/redo 后文档 hash 与初始一致；重做栈行为符合规范。
- [ ] **P2-AC3** 10 万针文档：平移/缩放中位帧率 ≥ 50 FPS，输入延迟 P95 < 50 ms（Chrome，GTX 1050 Ti 级；记录机器编号与测量脚本路径）。
- [ ] **P2-AC4** 修改单对象参数只重算该对象；其他色块针迹 hash 不变。
- [ ] **P2-AC5** Playwright 覆盖 6 条主流程（导入、建层、改参数、撤销、保存、导出）全部通过。
- [ ] **P2-AC6** 无阻塞性可访问性问题（键盘可达图层/参数；对比度 AA）。

## P3 图片矢量化 + 自动绣法

**进展（2026-10-30）**：确定性基线已跑通——Pillow 量化 + VTracer + 路径缩放 → CompileDocument
→ Ink/Stitch；合成图 2 层/2 路径 → 2,956 针/DST 9,407 B；网页“图片矢量化”可用，
支持颜色数 2–16、去白底（边缘洪泛，兼容非白背景）、扁平/照片风格（照片模式实验性）。
未做：30 张基准集、ML 分割、绣法自动分类、质量指标。详见 `docs/research/vectorization-baseline.md`。

**目标**：上传一张插画，90 秒内得到“可编辑、可上机”的初稿，而不是一堆碎路径。

**交付物**

- 分割服务（SAM2 / 颜色聚类 / 可选文本提示）；
- 矢量化服务（vtracer/potrace + 简化 + 拓扑修复 + 最小宽度）；
- 绣法分类与参数建议；
- 置信度与失败提示；
- 30 张基准图 + 人工参考 + 评测脚本。

**验收标准**

- [ ] **P3-AC1** 基准集区域 IoU 平均 ≥ 0.90；轮廓 Chamfer ≤ 0.3 mm。
- [ ] **P3-AC2** 自动绣法分类准确率 ≥ 85%（fill / satin / running 三类）。
- [ ] **P3-AC3** 初稿针数与人工参考偏差 ≤ 15%；无 < 0.5 mm 针迹、无 > 12.7 mm 单针。
- [ ] **P3-AC4** 2000 px 输入端到端 P95 ≤ 90 s；失败可重试且结果幂等（计费在 P4 接入，本阶段不承诺“不重复计费”）。
- [ ] **P3-AC5** 5 名设计师可用性测试：80% 的图在 10 分钟内改到“愿意试缝”。
- [ ] **P3-AC6** 低置信度区域必须显式标注，禁止静默输出。

**停止规则**：若 AC1/AC2 连续两轮迭代不达标，收缩到“Logo/扁平插画”单一场景，不追求照片级复杂图。

## P4 SaaS 化与生产加固

**目标**：多租户、可计费、可运维、可恢复。

**交付物**

- 账户/登录/团队/权限；项目 CRUD 与版本历史；
- 对象存储、异步任务、配额、审计日志；
- 监控（OTel）、错误追踪、备份与恢复演练；
- 安全基线（上传消毒、SSRF/XXE 防护、租户隔离）。

**验收标准**

- [ ] **P4-AC1** 跨租户访问测试全部 403；越权用例进入 CI。
- [ ] **P4-AC2** 50 并发导出任务：队列 P95 等待 < 60 s，无丢失、无重复扣费。
- [ ] **P4-AC3** 备份恢复演练：RTO ≤ 1 h，RPO ≤ 15 min，记录在案。
- [ ] **P4-AC4** OWASP Top 10 自查 + 依赖漏洞扫描无高危未处理项。
- [ ] **P4-AC5** 故障注入：worker 被杀、Redis 重启、S3 超时，任务可重试且幂等。
- [ ] **P4-AC6** 关键路径有 traceId，能在 5 分钟内定位一次失败导出。

## P5 机器格式与工艺覆盖

**进展（2026-10-30）**：网页已有 5 种绣框预设 + `/v1/stitch/check` 校验，
超出绣框为 error（禁用导出）、边距不足为 warning；6 种格式导出并读回，
矩阵见 `docs/reference/machine-formats.md`（JEF 暂用 pyembroidery 回退）；
`/v1/worksheet` 可下载 A4 工艺单（预览、参数、线色顺序、估算线量/工时）。
剩余：机型规则、分框、真实文件语料。

**目标**：主流机型/格式可用，边界情况有明确行为。

**交付物**

- DST / PES / EXP / JEF / VP3 / XXX 导入导出矩阵；
- 线色映射（品牌/线号/RGB）、换色顺序；
- 幅面/分框（hoop splitting）、起绣点、锁针/剪线策略；
- 50 份真实文件回归语料。

**验收标准**

- [ ] **P5-AC1** 6 种格式 × 导入/导出全部通过；50 份语料 round-trip 后针数/色块/换色不丢失（允许格式本身不支持的信息，但必须提示）。
- [ ] **P5-AC2** DST 导出在 3 种机型/仿真器上无“超幅面/非法跳针/色序错误”。
- [ ] **P5-AC3** 分框后的对齐误差 ≤ 0.2 mm；接缝处无重复/漏针。
- [ ] **P5-AC4** 每种格式的“不支持能力”在 UI 与文档中明确列出。

## P6 质量与“精美”

**目标**：从“能上机”到“愿意交付给客户”。

**前置条件**：必须锁定可试缝的机型、面料与打样伙伴；未满足时本阶段只能做离线质量改进，
不得对外宣称 production-certified。

**交付物**

- 绣法预设（面料 × 线径 × 密度 × 补偿）；
- 高级填充/渐变/纹理/字母（按需求优先级）；
- 试缝协议与缺陷分类；
- 视觉回归（渲染快照）。

**验收标准**

- [ ] **P6-AC1** 4 类面料（平纹棉、针织、帽料、毛巾）× 5 个图案，共 20 次试缝；人工评分平均 ≥ 4/5。
- [ ] **P6-AC2** 返工率 < 20%（以“需要重新制版”为返工）。
- [ ] **P6-AC3** 典型缺陷（露底、起皱、断线、堆线、错位）有检测规则或检查清单。
- [ ] **P6-AC4** 渲染快照回归：同一计划渲染像素差 < 0.1%。

## P7 实物照片反推针迹（R&D，独立）

**目标**：验证“拍一张成品照片 → 生成可用 DST”是否成立，而不是承诺功能。

**交付物**

- 50 组配对数据（DST + 缝合件 + 多角度照片）；
- 基线模型与评测报告；
- go/no-go 决策文档。

**验收标准**

- [ ] **P7-AC1** 数据集合规（肖像/品牌授权）、可复现拍摄协议。
- [ ] **P7-AC2** 基线：stitch-level F1 ≥ 0.75；Chamfer ≤ 0.6 mm；色块数误差 ≤ 1。F1 匹配规则预先写入评测脚本：同色块内、端点距离 ≤ 1.0 mm 且方向差 ≤ 30° 记为匹配；50 组仅用于评测与可行性，不用于训练大模型。
- [ ] **P7-AC3** 人类可用率 ≥ 50%（制版师认为“值得在此基础上修改”）。
- [ ] **P7-AC4** 明确失败边界（面料/颜色/光照/遮挡），写入产品说明。

**停止规则**：未达 AC2/AC3 则关闭该方向，只保留“照片 → 矢量化 → 制版”的降级路径。

## P8 Beta 运营

- 20 名种子用户；崩溃自由率 ≥ 99.5%（定义：会话数 − 崩溃会话数 / 会话数，按周统计）；
  导出成功率 ≥ 99%；
- 支持 SLA、反馈闭环、计费与退款流程；
- 公开 Beta 前完成许可证合规审查与隐私政策。

## 每周节奏

- 周一：定本周任务单（≤ 5 个），锁定依赖与验收；
- 周三：中期演示（可运行，不接受 PPT）；
