# 00 产品定义

## 1. 一句话

让没有工业制版软件经验的设计师，在浏览器里把一张图变成**能直接上机、线迹经得起放大看**的绣花文件；
让有经验的制版师，用 Illustrator 式的图层与针迹编辑，把自动结果修到生产级。

## 2. 用户与场景

| 用户 | 核心诉求 | 当前替代方案 | 我们的差异 |
| --- | --- | --- | --- |
| 独立设计师 / 小工作室 | 快速把插画、Logo 变成可打样文件 | 人工制版（¥50–300/稿）、Wilcom 等昂贵桌面软件 | 浏览器、按次付费、自动初稿 + 可改针 |
| 服装 / 帽饰品牌 | 批量、稳定、符合工厂机台 | 外包制版 + 反复打样 | 版本化工程、参数模板、可审计导出 |
| 资深制版师 | 精细控制针迹、顺序、密度 | Illustrator + Ink/Stitch | 保留 Ink/Stitch 能力，增加图层化针迹编辑与协作 |
| 工厂 / 打样间 | 来图快速报价、试排 | 人工估针数 | 自动针数 / 工时 / 用料估算 |

## 3. 范围（MVP，Phase 0–5）

**做：**

- 账户、项目、素材上传、自动保存；
- 位图 → 分层矢量 → 自动绣法（fill / satin / running）→ 可编辑针迹；
- 图层 / 对象 / 针迹参数编辑，撤销重做；
- 针迹预览（按真实针脚渲染）、密度 / 针数 / 用色统计；
- 导出 DST（主）、PES / JEF / VP3 / EXP（Phase 5）；
- 导入 DST / PES / SVG，继续编辑；
- 服务端渲染 PNG / PDF 工艺单。

**暂不做（明确非目标）：**

- 不做通用矢量绘图软件（不替代 Illustrator）；
- 不做云端刺绣机控制 / 直接驱动设备；
- 不做面料仿真级 3D 试衣；
- MVP 不承诺“任意照片一键出精品”，照片反推针迹是 Phase 7 的 R&D；
- 不做跨店交易市场。

## 4. 产品原则

1. **可上机优先于好看**：任何自动结果必须通过机器约束校验（针长、密度、跳针、色序、幅面）。
2. **非破坏式**：原图、矢量、绣法参数、生成针迹分层保存；改参数可重算，不丢手工修改。
3. **所见即所得**：预览的每一针与导出文件一致（同一份 StitchPlan，不允许两套几何）。
4. **可解释**：自动制版给出“为什么这样排针”（区域分类、方向、密度来源）。
5. **人在回路**：自动结果默认是草稿，一键进入图层编辑；不假装全自动。

## 5. 成功指标（Beta 前）

| 维度 | 指标 | 目标 |
| --- | --- | --- |
| 可用性 | 上传一张 2000px 插画 → 得到可导出初稿 | ≤ 90 秒（P95） |
| 质量 | 30 张基准图，人工评分（1–5） | 平均 ≥ 4.0 |
| 保真 | 区域 IoU（对人工矢量化参考） | ≥ 0.90 |
| 工艺 | 导出文件通过自检规则 | 100% |
| 稳定 | 导出失败率 | < 0.5% |
| 生产 | 试缝样片返工率（人类评估） | < 20% |
| 性能 | 10 万针编辑交互 | ≥ 50 FPS |

## 6. 关键术语

- **Digitizing（制版）**：把 artwork 转成机器可执行的针迹序列。
- **Stitch plan**：颜色块 + 每针坐标 + 命令（stitch/jump/trim/color change/stop）。
- **Underlay（打底）**：主针迹前的固定层，防止面料起皱、露底。
- **Pull compensation（拉布补偿）**：抵消绣线收缩导致的尺寸偏差。
- **Satin / Tatami / Running**：缎面、榻榻米填充、走线三种基础绣法。
- **DST**：Tajima 二进制格式，单位 0.1 mm，无机台无关的颜色名（3 字母线号）。
- **Hoop**：绣花框幅面；超出需分框（hooping/splitting）。
