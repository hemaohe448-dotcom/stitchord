# 图片矢量化基线（P3 第一版）

> 目标：先跑通“上传图片 → 得到可编辑的绣花文档 → 生成针迹”，
> 再用 ML 分割/边缘优化替换基线。**当前不是“精美”方案，也没有 ML 模型。**

## 1. 流水线

```text
PNG/JPG/WEBP
 → Pillow：压到最长边 1000 px、透明合成白底
 → 中位切分量化（maxColors 2–16，默认 8）
 → VTracer 0.6.15：color / stacked / spline
 → 解析 <path d/fill/translate>
 → 坐标从 px 缩放到 mm（默认宽 100 mm）
 → 去掉近白背景（可选）
 → CompileDocument（每个颜色一个图层）
 → /v1/digitize（Ink/Stitch）→ StitchPlan/DST
```

实现：`services/digitizer/app/vectorize.py`；接口：`POST /v1/vectorize`（multipart）。
前端“工程 → 图片矢量化”按钮直接调用，成功后自动生成针迹。

## 1.1 已补的两项

- **边缘洪泛去背景**：从四角对连通背景色做 flood fill（容差 24），再合成白底；
  不再只认“近白色”，可处理蓝/灰纯色照片背景（测试：蓝底红块）。
- **照片风格（实验）**：中值滤波 3×3 + 高斯 0.6 + CIELAB k-means 量化，减少噪点/碎色块；
  不改变“颜色量化 + 轮廓”的本质，仍不是 ML 分割。

## 2. 实测

合成图：120×80 PNG，白底 + 红矩形 + 蓝圆。

| 指标 | 结果 |
| --- | --- |
| 图层 | 2（红/蓝，白底已移除） |
| 路径 | 2 |
| 文档尺寸 | 100 × 66.667 mm |
| 生成针迹 | 2 色块 / 2,956 针 |
| DST | 9,407 B |
| 测试 | 3.11 全量 77 passed |

## 3. 已知限制

- **没有 ML**：不做语义分割、不识别文字/Logo、不做遮挡层级；
- 只适合扁平色块/矢量风插画；照片、渐变、纹理效果差；
- 背景移除是“近白阈值”启发式，不是抠图模型；
- 每个颜色最多 200 条路径，超出会截断；
- 没有最小特征宽度/自交修复；细节可能产生烂针（后续加规则）；
- 颜色是量化后的近似值，不是线色目录匹配。
